# AM Developers

Портфолио с семью проектами для репозитория `amdevelopersgroup/amdevelopers-portfolio`.
Загрузите содержимое этого архива прямо в корень ветки `main`.
В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.

Адрес сайта после публикации: https://amdevelopersgroup.github.io/amdevelopers-portfolio/

Отдельный сервер формы опубликован на Netlify. Доставку заявки из формы
портфолио в Gmail ещё нужно проверить после публикации сайта.

Подробности и текущий статус подключения — в `README.txt`.
